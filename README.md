# Совет по продвижению стареет быстрее, чем ты успеваешь его применить, и дату протухания в нём никто не проставил

Четырнадцать книжных линз отвечают каждая только из своей книги, платформенная тактика вынесена
пятнадцатой линзой с полем даты актуальности, а расхождение между ними попадает в вердикт
отдельной строкой «канон vs 2026».

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install advisor-influence@jadlis
```

Ключей, платных сервисов и внешних CLI здесь нет; настройка одна — папка, куда совет пишет
вердикты, журнал и профиль.

![Ростер разложен на два слоя: четырнадцать книжных линз и отдельный платформенный слой с датой актуальности](docs/img/hero-jadlis-advisor-influence.webp)

Текстом: слева вопрос про продвижение, справа два слоя ростера — книжный без даты и платформенный
с проставленной датой, — и стрелка от их расхождения в строку вердикта «канон vs 2026».

Это моё рабочее место, выложенное как есть, а не продукт: чем перестал пользоваться — убрал.

## Было → стало

| Руками | Чатом с ИИ | Этим плагином |
|---|---|---|
| **Откуда берётся совет.** Берёшь книгу, которую прочитал последней, и меряешь ею весь запуск. | Отвечает смесью всех книг сразу; из какой книги пришёл пункт, по ответу не видно. | Каждая линза читает свою книгу и отвечает только из неё, а каждый пункт несёт citation-тег своего конспекта. |
| **Возраст совета.** В тексте не написано, где вечнозелёный принцип, а где тактика умершей платформы. | Про психологию влияния и про алгоритм этого месяца звучит одинаково уверенно. | Платформенный слой вынесен отдельной линзой с полем `data_as_of` и порогом устаревания; книжные линзы тактику платформ не выдают. |
| **Что значит совпадение советов.** Когда два источника сошлись, это выглядит подтверждением. | Согласие внутри одного ответа ничего не проверяет: источник один. | Линзы не видят ответов друг друга; совпавшие и спорные утверждения отбирает куратор и голосуют три скептика. |
| **Куда девается спорное.** Возражение приходится придумывать самому, и обычно позже, чем нужно. | Возражения не будет: ответ достроит недостающее. | Скептики голосуют по каждому утверждению: опровергнутое не идёт в «Что делать», спорное уезжает в «Против» и помечается в карте консенсуса. |
| **Где лежит разбор через полгода.** В переписке, которую уже не найти. | История чата не разложена по темам и не привязана к твоему контексту. | Вердикт кладётся файлом в твою папку памяти, строка — в журнал советов, профиль совета обновляется к следующему запросу. |

## Как это работает

![Вопрос проходит интервью, расходится на пятнадцать линз, решающие утверждения голосуются скептиками и сводятся в один вердикт](docs/img/how-jadlis-advisor-influence.webp)

На входе — твой вопрос и постоянная секция профиля, которую ведёшь ты, а совет только читает.
Внутри — линзы сдают уточняющие вопросы, интервью снимает неизвестное, пятнадцать линз отвечают
порознь, куратор отбирает решающие утверждения, по каждому голосуют три скептика.
На выходе — один файл: что делать, карта консенсуса с колонкой леджера, SWOT и слепые зоны.

Текстом: вопрос → интервью по вопросам самих линз → пятнадцать параллельных ответов → отбор
решающих утверждений → голосование скептиков → вердикт файлом в папке памяти.

Делит ростер на два слоя именно эта постановка. Четырнадцать линз — книги: Cialdini, Hormozi,
Godin, Heath, Berger, Miller, Kane, GaryVee, Kleon, Weinberg & Mares, Ferrazzi, Schaefer, Flynn,
Dunford. Пятнадцатая — «Тактика 2026»: не книга, а синтез платформенных ресёрчей с полем
`data_as_of: 2026-07` и порогом устаревания 2027-01; после порога линза сама предупреждает, что
данные старше полугода, и понижает уверенность по платформо-зависимым тегам.

Разводит слои протокол валидатора. Тактические вопросы — алгоритмы, форматы, каналы, KPI —
решаются приоритетом платформенного слоя; принципиальные — психология, отношения,
позиционирование, доверие — приоритетом книжного канона, и платформенный слой канон
автоматически не переписывает. Расхождение обязано попасть в карту консенсуса строкой
«канон vs 2026».

Дисконтирует валидатор и сами книги: у шести линз известный скос записан прямо в ростер и
применяется обязательно — Cialdini и Berger читаются как доалгоритмический фундамент, а не как
тактика; Ferrazzi — как принципы отношений, каналы у него оффлайновой эпохи; Hormozi применяется
к лидгену и монетизации, а не к органическому росту аудитории; количественные claims Kane идут
с пометкой «оценка автора, не аудировано»; «быть везде» у GaryVee дисконтируется против консенсуса
фокуса. Применённые дисконты печатаются в шапке вердикта.

Не выдаёт совет вердикт при кворуме ниже десяти из пятнадцати: тогда показываются ответы линз как
есть, без синтеза. Бывает и обратное — после голосования скептиков от консенсуса не остаётся
ничего; это ответ «оснований нет», а не поломка.

## Установка и первый запуск

**а) Текст для вставки агенту.** Скопируй целиком в чат Claude Code:

```
Ты — установщик. Поставь на этот Mac плагин advisor-influence из маркетплейса jadlis.
Выполни ровно эти команды, дословно, ничего не сокращая:
1. claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
2. claude plugin install advisor-influence@jadlis
3. claude plugin list — покажи мне строку про advisor-influence и его версию.
API-ключей и внешних CLI плагину не нужно. Спросят одну настройку — MEMORY_DIR, папку
для вердиктов совета; путь называю я, по умолчанию ~/advisors-memory.
Перед каждой командой покажи её мне целиком и дождись «да». Сказал «нет» — не выполняй,
скажи, что именно пропустил, и иди дальше.
Команда вернула ошибку — остановись, покажи вывод, к следующей не переходи.
```

**б) Команды руками.**

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install advisor-influence@jadlis
claude plugin list
```

Первая команда ничего не ставит — она добавляет маркетплейс. Ставит только вторая, и снимается
она одной строкой: `claude plugin uninstall advisor-influence@jadlis --keep-data`.

Папку памяти можно задать сразу: `claude plugin install advisor-influence@jadlis --config
MEMORY_DIR=~/advisors-memory`. Она общая для всех советов Jadlis — можно указать одну и ту же.
Первый запуск разворачивает в ней скелет: `Профили/`, `Журнал советов.md`, `Журнал решений.md`,
`Свайп-файл.md`, `Советы.md`; вердикты этого совета уходят в подпапку `Медийность`, служебные
файлы прогона — в `_runs` и удаляются после записи. Поменять папку потом можно только
переустановкой с `--config`: на уже установленном плагине этот флаг молча ничего не меняет
(проверено 07.09.2026). Пока папка не задана, совет останавливается на входе и не пишет вердикт
в текущую рабочую папку.

**в) Короткая команда.** Открой Claude Code в папке, где работаешь, и набери:

```
/advisor-influence <вопрос>
```

Не находится — сверь имя строкой `claude plugin list`. Отвечает совет на языке запроса,
citation-теги остаются английскими. Секцию `## Profile` в файле профиля ведёшь ты: совет читает
её целиком, не переписывает и не переспрашивает то, что там уже есть.

## Границы, стоимость, обновление

**Чего не делает.** Не ходит в интернет и не проверяет факты о твоём рынке: линзы отвечают из
конспектов, свежих данных о твоей нише у них нет. Не считает и не даёт цифр по твоим каналам —
числа приносишь ты, и их статус (факт, гипотеза, n=1) отмечаешь сам, иначе скептики снесут вывод
вместе с непроверенным допущением. Не пишет за тебя посты и лендинги — здесь разбор, а не
конвейер текста. Не выдаёт citation-теги за библиографию: тег указывает на блок конспекта внутри
плагина, а не на страницу книги. Не правится по месту — репозиторий собирается генератором из
приватного источника, CI сверяет хеш содержимого, так что присланная сюда правка файла не
переживёт релиз; ошибка → issue. Ничего не пишет за пределами твоей папки памяти.

**Что нужно.** Ключей не нужно: ни API-ключей, ни MCP-серверов, ни платных сервисов, ни внешних
бинарников — скрипт разворачивания скелета написан на `/bin/sh` и ничего не устанавливает. Нужна
подписка Claude Code: прогон целиком идёт из твоей квоты. Нужна одна настройка — `MEMORY_DIR`,
папка на твоём диске; по умолчанию `~/advisors-memory`.

[уточнить] — срок, к которому платформенный слой будет обновлён, в репозитории не зафиксирован:
порог устаревания проставлен, обязательства по обновлению — нет.

**Порядок расхода токенов.** Тяжёлый прогон — десятки субагентов из твоей квоты: интервью-харвест,
пятнадцать линз параллельно, куратор, по три скептика на каждое отобранное утверждение и валидатор,
и все они работают на Opus с высоким усилием. Совет не деградирует частично: исчерпанное сессионное
окно валит фан-аут целиком — все линзы возвращают отказ, кворум ноль, вердикта нет. Поэтому перед
запуском смотри остаток окна, а несколько советов подряд в одно окно не планируй. Это инструмент
для вопросов, которые не переигрываются.

**Проверено там, где я работаю:** мой Mac, моя подписка. Где ещё это работает — [уточнить].

**Условия использования.** Лицензии нет: все права сохранены за автором. Читать и
пользоваться лично можно. Коммерческое использование, переиздание и включение в свои
продукты — по договорённости со мной.

**Обновление.** У стороннего маркетплейса авто-обновление на твоей стороне выключено: пока не
запустишь первую команду, у тебя остаётся та версия, которую ты поставил.

```
claude plugin marketplace update jadlis
claude plugin update advisor-influence@jadlis
claude plugin list
```

Переустановка, если что-то встало криво:

```
claude plugin uninstall advisor-influence@jadlis --keep-data && claude plugin install advisor-influence@jadlis
```
